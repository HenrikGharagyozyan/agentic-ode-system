What the project does

You give it a task in plain text (here task5.md: fit a neural ODE to the Silverbox oscillator data). Four roles work on it inside a LangGraph StateGraph, until a script has really run and printed a free-run RMSE, or 8 decisions are used up.

orchestratorReads the whole dialogue and decides who speaks next, with an instruction and a reason, or finish. No tools.
scientistWrites the theory and plan: ODE, network, integrator, training, free-run test, numbered steps. No tools.
generalAnswers side questions (what is V1, what does RMSE measure). No tools, never plans.
executorThe only role with tools: write_file, run_file. Writes a script from the plan, runs it, reports the real output.
  1. The state is the dialogue. Every role reads all turns and appends one. Roles never call each other.
  2. Routing is decided by a model, through structured output. No keyword table, no fixed order.
  3. Only the executor touches code. It is the only node that calls bind_tools.
  4. Results must be real. finish is allowed only after a script exited with 0 and printed FREE_RUN_TEST_RMSE, checked against records built from real subprocess output.

One run, step by step

agentic-ode run → cli.main → cmd_run → Settings.from_env → run_task, which builds the graph and streams it. After every graph step the new turns are printed and the transcript is saved.

def run_file(workdir: Path, filename: str, timeout: float) -> RunResult:
    """Run a file of the working directory with the current interpreter."""
    check_filename(filename)
    if not (workdir / filename).exists():
        return RunResult(exit_code=None, stdout="", stderr=f"ERROR: {filename} does not exist")
    try:
        p = subprocess.run(
            [sys.executable, filename], cwd=workdir, capture_output=True, text=True, timeout=timeout
        )
    except subprocess.TimeoutExpired as e:
        return RunResult(
            exit_code=None,
            stdout=_decode(e.stdout),
            stderr=_decode(e.stderr) + f"\nTIMEOUT: killed after {timeout:g} s",
            timed_out=True,
        )
    return RunResult(exit_code=p.returncode, stdout=p.stdout, stderr=p.stderr)
